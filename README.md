# CBK CarAudio & Security — Website premium

Primera versión funcional de la web de **CBK CarAudio & Security** (David Prieto Hernando), taller de seguridad automotriz y CarAudio en Collado Villalba, Madrid.

## Contenido implementado
- Home hero cinematográfico con diseño oscuro, acento naranja y tipografía premium.
- Secciones: servicios, seguridad, tecnología, sobre CBK, trabajos, proceso, preguntas frecuentes, contacto y ubicación.
- Catálogo de los 13 servicios del briefing, con consultas WhatsApp preconfiguradas.
- Responsive, navegación móvil, CTA de WhatsApp, redes sociales, metadatos básicos, JSON-LD LocalBusiness, robots.txt y sitemap.xml.
- Sin formularios de almacenamiento ni rastreadores analíticos activos en esta primera versión.

## Visualización / despliegue
La web es **HTML + CSS + JS estático**. Abrir `index.html` en un navegador para previsualizar. Para publicar en Vercel, importar el repositorio y elegir Framework Preset **Other** y directorio de salida `.` (sin build command). No cambiar los DNS de `cbkaudio.com` hasta auditar la web previa y sus URLs indexadas.
